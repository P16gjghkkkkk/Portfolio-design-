PROMISE CHUKWUEMEKA — DARK BENTO PORTFOLIO

Files
- index.html: page structure and portfolio content
- style.css: dark bento-grid styling and responsive breakpoints
- script.js: mobile navigation and dynamic footer year

Deploy to the existing GitHub Pages repository
1. Open https://github.com/P16gjghkkkkk/-promise-portfolio
2. Open index.html, choose the pencil/Edit button, replace the file contents with the new index.html, and commit changes.
3. Repeat for style.css and script.js.
4. Wait a minute or two, then open https://p16gjghkkkkk.github.io/-promise-portfolio/
5. If the old version remains, refresh the page or clear the browser cache.

The site uses no build step or framework, so it is compatible with GitHub Pages static hosting.

Accuracy notes
- Portfolio content is based on existing portfolio/CV material.
- The education dates are labelled as listed in the CV and should be confirmed before changing them.
- No proficiency ratings, client work, awards, or unsupported achievements have been added.
- Only previously supplied email and phone/WhatsApp contact methods are included.
